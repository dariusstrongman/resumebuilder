# ATSHack vNext — Round 3 concepts

Round 3 fixes the biggest remaining weakness from Round 2: the site could look premium while the resume transformation itself was only moderately good and, worse, some strong-looking details were not traceable to the source example.

## Round 3 rules

- Current live `atshack.com` remains untouched.
- Hosted previews are mirrors; this branch is source truth.
- The quality of the resume transformation is part of website quality.
- All three concepts use the same canonical illustrative candidate/source packet and target role so the directions can be judged fairly.
- Every stronger resume phrase must be traceable to supplied source evidence.
- Unsupported target requirements remain explicit gaps. They are never inserted merely because they are useful keywords.
- No invented years, employers, credentials, metrics, volumes, certifications, outcomes, or hiring probabilities.
- Illustrative examples are clearly labeled as illustrative.
- No guaranteed ATS passage, interview probability, or fake hireability score.
- Every direction retains a distinct signature scroll-driven mechanic.
- Mobile behavior is intentionally responsive rather than a desktop shrink.
- These are concept studies only. They contain no live Stripe, Supabase, or n8n wiring and do not modify production.

## Domain-quality artifacts

- `industry-excellence.md` defines what an excellent ATSHack resume transformation must demonstrate.
- `canonical-transformation.json` is the shared truth packet used by the Round 3 concepts.

The canonical example targets an **Operations Specialist** role. Supported requirements include inventory reconciliation, Excel, KPI reporting, cross-functional coordination, and process improvement. **SOP ownership is intentionally unsupported and must stay out of the resume.**

## Directions

1. `01-system-scan` — evidence map: target requirement → source evidence → supported rewrite / explicit gap.
2. `02-editorial-precision` — premium editorial rewrite: weak language is annotated and replaced with source-backed operating evidence.
3. `03-outcome-engine` — version lineage: the source-checked tailored resume remains connected to the application, interview context, and next action.

## Advancement gate

Do not choose a winner from source code alone. Round 3 still needs actual desktop/mobile rendering and independent visual review. A concept should not advance simply because the domain logic is now stronger.
